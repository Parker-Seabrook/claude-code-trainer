# Lesson conventions

- File name is NN-short-slug.md, numbered in learning order (01, 02, ...), with the same stem as its quiz file.
- Start with one `# Title`, then 3 to 5 `## Sections`.
- Explain one idea at a time. Lead with a concrete example, then state the rule.
- Plain language. Define any Claude Code term the first time it appears.
- Include a `## Try it` section with steps the reader does in their own terminal.
- End with `## Three things to remember`, exactly three bullets.
- Target 300 to 600 words.
- Mention common mistakes where they fit, like the double-! mistake in lesson 01.
